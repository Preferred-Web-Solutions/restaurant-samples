Accessibility statement

Version 1.1 · Last updated November 5, 2026

This website was built with accessibility in mind. Our goal is for everyone, including people who use screen readers, keyboards, magnification or other assistive technology, to be able to use it.

What we did

  • We aimed for the Web Content Accessibility Guidelines (WCAG) 2.1, level AA.
  • Menus, prices and hours are real text, not pictures or PDFs.
  • Photos have text descriptions. Text has strong color contrast.
  • Everything works with a keyboard, with a visible focus outline and a "Skip to content" link.
  • Slideshows can be paused, and motion is reduced if your device asks for it.
  • The page still works when zoomed to 200%.
  • Each page was checked with the axe automated accessibility checker and by tabbing through it by hand.

Known limits

Automated tools find only some problems, so we do not claim the site is fully compliant. If something does not work for you, we want to know.

Tell us about a problem

Use the Report a website issue form or email preferredwebsolutions@gmail.com. We will look into it and reply if you leave contact details.
